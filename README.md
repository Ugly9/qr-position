# QR Position DC2/DC3

Standalone PWA for warehouse QR positions.

- DC2: aisles 12–123, positions 1–168
- DC3: aisles 1–41, positions 1–148
- Floor is always 00
- DC2 prefix: CZSYR2
- DC3 prefix: CZSYR3
- Works as an installable PWA and caches core files for offline use after the first online load.
